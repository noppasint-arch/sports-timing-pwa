# Device Role Assignment Guide

## 30-Metre Sprint Test

**Devices needed: 2 (minimum) — 4 (with splits)**

| Device | Role   | Where to place it                        |
|--------|--------|------------------------------------------|
| 1      | START  | Exactly at the start line (0 m)          |
| 2      | FINISH | Exactly at 30 m                          |
| 3*     | SPLIT  | Optional — at 10 m mark                 |
| 4*     | SPLIT2 | Optional — at 20 m mark                 |

*Optional gates — assign these roles if the device is available.

**Physical placement:**
- Lay the phone flat on a cone or stand so the screen faces upward
- Align the green line marker on screen with the tape/cone on the ground
- Athlete's foot crossing the line = the trigger moment
- For the START gate, the athlete triggers the button themselves (crouching start) or the coach triggers it on the athlete's first movement

## Y-Shape Agility Test

**Devices needed: 4**

```
              FORWARD (Device 4)
                   |
                   | ← 5–6 m
                   |
LEFT (Dev 2) ──── ● ──── RIGHT (Dev 3)
              CENTER (Dev 1)
         ← 3–4 m each side →
```

| Device | Role    | Where to place it                                    |
|--------|---------|------------------------------------------------------|
| 1      | CENTER  | At the junction of the Y (coach/controller device)   |
| 2      | LEFT    | End of the left arm                                  |
| 3      | RIGHT   | End of the right arm                                 |
| 4      | FORWARD | End of the forward arm                               |

**How it works:**
1. CENTER device randomly selects a direction and displays an arrow + plays a beep
2. Athlete (at center) reacts and sprints to the indicated arm
3. Endpoint device at the indicated arm: press the button when athlete arrives
4. CENTER records reaction time + travel time for each rep

**Arm lengths:** Typically 3–6 m. Use consistent distances across all sessions for valid comparisons.

## Illinois Agility Test

**Devices needed: 2**

```
(0,0) ●────────────────────────────────● (5,0)
      |                                |
      |   ● ← cones (coach sets up)   |
      |                                |
      |   ●   ●   ●   ●              |
      |                                |
(0,10)●────────────────────────────────● (5,10)
    START                           FINISH
  (Device 1)                      (Device 2)
```

| Device | Role   | Where to place it                                           |
|--------|--------|-------------------------------------------------------------|
| 1      | START  | Bottom-left corner — athlete starts lying face-down here    |
| 2      | FINISH | Bottom-right corner — 5 m from start, on same end line      |

**Coach sets up physically (no sensors on cones):**
- 4 corner cones at a 10 m × 5 m rectangle
- 4 slalom cones spaced evenly along the centre line
- Athlete course: up the left side → around top-left → weave through 4 centre cones → around top-right → down the right side → finish

**Sensor logic:** Identical to the 30m Sprint — START triggers begin, FINISH triggers end. The agility course is performed physically between those two events.

## General Placement Rules (All Tests)

1. **Screen facing upward** works best — use a phone stand or tape the device to a flat cone.
2. **Align the green line** on screen with your physical marker before confirming ready.
3. **Confirm marker** on every device before the host starts the trial.
4. **Re-sync** between sessions if any device was moved or restarted.
5. **Audio trigger** (clap/beep detection) is an alternative to button press — enable in Settings if your setup benefits from hands-free triggering.
